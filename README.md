# Telegram-бот для продажи VPN-подписок

Telegram-бот для продажи и управления
VLESS VPN-подписками, ориентированный на использование в реальном проекте.

## Возможности

- Управление подписками через Telegram
- Несколько тарифных планов
- Продление подписки
- Автоматическая обработка истёкших подписок
- Промокоды
- Реферальная система
- Оплата через криптовалюту
- Интеграция с API 3x-UI
- Ограничение трафика
- Панель администратора
- Фоновые задачи по расписанию
